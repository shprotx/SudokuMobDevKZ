Privacy Policy — Sudoku just for fun

Last updated: May 2026

Data collection

The app collects a minimal set of data needed for game statistics: time, errors, and game results. Data is linked to an anonymous device ID and contains no personal information.

Data storage

Game statistics are stored locally and synced with Firebase Realtime Database for the player comparison feature. You can delete your data at any time via Settings → Reset statistics.

Data usage

Collected data is used exclusively for:

  • Displaying your game statistics
  • Calculating your percentile among other players

Data is not shared with third parties or used for advertising.

Leaderboard

If you choose a nickname to appear on the leaderboard, that nickname and your game results are stored in Firebase and shown to other players. You can change or remove your nickname at any time in Settings.

Feedback

When you submit feedback, the message text along with context information (app version, device model, OS version, locale, and sign-in status) is sent to the developer via a Firebase Cloud Function. No personal data is collected. The data is used solely to respond to your feedback and improve the app.

Your rights

  • Delete all your data via app settings
  • Disable statistics sync
  • Request server data deletion by contacting the developer

Policy changes

We may update this policy. The current version is always available in the app and on this page.

Contact

Политика конфиденциальности — Sudoku just for fun

Последнее обновление: май 2026

Сбор данных

Приложение собирает минимальный набор данных, необходимый для работы игровой статистики: время прохождения, количество ошибок и результаты игр. Данные привязаны к анонимному идентификатору устройства и не содержат персональной информации.

Хранение данных

Игровая статистика хранится локально на устройстве и синхронизируется с Firebase Realtime Database для обеспечения функции сравнения с другими игроками. Вы можете удалить свои данные в любой момент через раздел «Настройки» → «Сбросить статистику».

Использование данных

Собранные данные используются исключительно для:

  • Отображения вашей игровой статистики
  • Расчёта вашего процентиля среди других игроков

Данные не передаются третьим лицам и не используются в рекламных целях.

Таблица лидеров

Если вы выбираете никнейм для таблицы лидеров, этот никнейм и ваши игровые результаты сохраняются в Firebase и видны другим игрокам. Никнейм можно изменить или удалить в любой момент в настройках.

Обратная связь

При отправке фидбека текст сообщения вместе с контекстной информацией (версия приложения, модель устройства, версия ОС, язык, статус входа) передаётся разработчику через Firebase Cloud Function. Личные данные не собираются. Данные используются исключительно для ответа на ваш отзыв и улучшения приложения.

Ваши права

  • Удалить все свои данные через настройки приложения
  • Отключить синхронизацию статистики
  • Запросить удаление данных с сервера, связавшись с разработчиком

Изменения политики

Мы можем обновлять данную политику. Актуальная версия всегда доступна в приложении и на этой странице.

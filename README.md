# SudokuMobDevKZ

Мобильная головоломка Судоку для Android. Распространяется через APK — скачивайте последнюю версию в [Releases](https://github.com/shprotx/SudokuMobDevKZ/releases/latest).

## Особенности

- 3 уровня сложности
- Подробный учет статистики с онлайн-перцентилями (Firebase)
- 3 темы (светлая, тёмная, зелёная)
- Автообновление — приложение само проверяет наличие новой версии при запуске
- Возможность включать бесконечные подсказки
- Возможность отключить подсчет ошибок
- Автосохранение и возможность продолжить игру или начать заново
- Заметки с автоматическим пересчётом при заполнении ячеек
- Полностью израсходованные цифры скрываются
- Отмена последнего хода
- Локализация: EN / RU / KK

## Стек

- Java 100%
- MVVM + Navigation Component
- Room
- ViewBinding
- Firebase Realtime Database (REST API, без SDK)
- Neumorphism UI
- CI/CD: GitHub Actions (автосборка релизного APK при мерже в master)
